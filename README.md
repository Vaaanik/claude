# Свет и тревога

Два инструмента для Днепропетровской области:

1. **Telegram-бот** — пишет, когда меняется график отключений вашей группы,
   за 30 минут до отключения и перед включением, а также пересылает
   объявления ДТЭК (например, об экстренных отключениях).
2. **Android-виджет** — показывает на главном экране, есть ли воздушная
   тревога в области, и ближайшее отключение света.

## 1. Telegram-бот

Бот запускается в GitHub Actions каждые ~5 минут (`.github/workflows/outages.yml`),
отдельный сервер не нужен. Расписание работает только из основной ветки (`main`).

Настройка:

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`,
   придумайте имя — получите **токен** вида `123456:ABC...`.
2. Откройте своего нового бота и нажмите **Start** (без этого бот не может вам писать).
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1.
4. **Actions → «Отключения света» → Run workflow.** Бот пришлёт текущий график и
   ваш `chat id`. Добавьте его вторым секретом `TELEGRAM_CHAT_ID`, чтобы бот
   вас не потерял.

Необязательные настройки (вкладка **Variables** там же):

| Переменная       | По умолчанию | Что делает                                    |
|------------------|--------------|-----------------------------------------------|
| `GROUP`          | `4.2`        | Ваша группа (очередь) отключений              |
| `REMIND_MINUTES` | `30`         | За сколько минут предупреждать                |
| `ALERTS`         | `0`          | `1` — писать и о начале/отбое тревоги         |

Ограничения: GitHub запускает расписание неровно (задержки 5–15 минут бывают),
поэтому напоминание может прийти не ровно за 30 минут. Если в репозитории 60 дней
нет коммитов, GitHub отключает расписание — его нужно включить заново во вкладке Actions.

Проверить локально (без токена сообщения просто печатаются):

```
GROUP=4.1 python3 bot/check.py
```

## 2. Виджет для Android

Исходники — в `android/`. APK собирается автоматически
(`.github/workflows/android.yml`) и после слияния в `main` появляется в разделе
**Releases** репозитория.

1. Скачайте `svitlo-widget.apk` на телефон и откройте его; разрешите установку
   из этого источника.
2. Откройте приложение «Тревога и свет», выберите область и группу.
3. Долгое нажатие на пустом месте главного экрана → **Виджеты** → «Тревога и свет».

Виджет красный при тревоге и зелёный без неё, обновляется раз в пару минут, пока
экран включён; нажатие обновляет сразу. Это справочный индикатор с задержкой до
нескольких минут — для звукового оповещения держите включённым официальное
приложение «Повітряна тривога».

## Источники данных

- График ДТЭК: [Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua)
  (копия данных с сайта ДТЭК Днепровские электросети).
- Тревоги: `https://ubilling.net.ua/aerialalerts/`.

Оба источника — сторонние и могут измениться или отключиться.
