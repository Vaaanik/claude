# Тревога и свет

Android-приложение с виджетом для Кривого Рога:

- **Воздушная тревога** — по Telegram-каналу
  [sirena_kryvyi_rih](https://t.me/sirena_kryvyi_rih). Проверка каждые 10 секунд,
  при тревоге и отбое приходит уведомление, виджет становится красным/зелёным.
- **Угрозы: что и куда летит** — из четырёх каналов (проверка каждые 15 секунд):
  [Воздушные силы](https://t.me/kpszsu), [Александр Вилкул](https://t.me/vilkul),
  [Майстерня_KR](https://t.me/IMS_KR_TM) и [Оборона Кривбасу](https://t.me/oborona_kr).
  Показывается только то, что касается Кривого Рога и района, без рекламы и
  подписей. Приходит уведомлением и 30 минут держится на виджете.
- **Отключения света** — график вашей группы прямо с сайта
  [ДТЭК Днепровские электросети](https://www.dtek-dnem.com.ua/ua/shutdowns),
  проверка каждые 5 минут. Уведомления: график изменился, за 30 минут до
  отключения и перед включением.

В приложении три блока: крупный статус тревоги, **ход тревоги** — все сообщения
о целях за текущую (или последнюю) тревогу по порядку, новые сверху, — и **свет
на весь день**: полосы суток на сегодня и завтра с отметкой текущего времени.

Всё работает на самом телефоне, сторонние серверы и посредники не используются.

## Установка

1. Скачайте `svitlo-widget.apk` (раздел **Releases** после слияния в `main`),
   откройте на телефоне и разрешите установку из этого источника.
2. Откройте «Тревога и свет», разрешите уведомления.
3. Нажмите **«Разрешить работу в фоне без ограничений»** — иначе Samsung
   будет останавливать слежение при выключенном экране.
4. Проверьте группу отключений и нажмите «Сохранить и обновить».
5. Виджет: долгое нажатие на пустом месте главного экрана → **Виджеты** →
   «Тревога и свет».

В шторке будет постоянное уведомление приложения — это признак, что слежение
работает; не смахивайте его.

## Как это устроено и чего ждать

- Задержка по тревоге — до ~10–15 секунд после сообщения в канале. Мгновенной
  доставки без входа в аккаунт Telegram получить нельзя.
- Постоянная работа в фоне расходует батарею и около 150 МБ трафика в сутки.
- Если данные не удаётся проверить дольше 1,5 минут, виджет становится серым
  («Нет связи»), а не показывает устаревшее «тревоги нет».
- Сайт ДТЭК пускает только настоящий браузер, поэтому приложение открывает его
  в невидимом окне браузера. Если сайт недоступен, показывается последний
  загруженный график и время загрузки.
- Приложение — дополнительный индикатор. Официальное приложение «Повітряна
  тривога» лучше оставить включённым.

### Каналы об угрозах

Список каналов и слов-названий меняется в приложении.

- Обычный канал (например `kpszsu`) пишет про всю страну — из него берутся
  только фразы со словами из списков «мой город» и «рядом». Знак `?` перед
  словом — учитывать только вместе с «Дніпропетровщина» (у названия есть тёзки).
- Местный канал помечается звёздочкой (`vilkul*`): в нём всё про город, поэтому
  берутся короткие посты со словами об атаке целиком.
- `IMS_KR_TM*` и `oborona_kr*` — неофициальные каналы наблюдателей, ведут цель
  по районам города. Их уведомления идут отдельной категорией «Местные каналы»,
  звук которой можно отключить в настройках уведомлений телефона.
- Ещё можно добавить `rudanatv*`, `svoiKR*` — тоже неофициальные.
- Отбоя по БпЛА каналы не дают, поэтому сообщение просто исчезает с виджета
  через 30 минут. Настоящий отбой — только по каналу сирены.

Канал и группу можно поменять в приложении. Исходники — в `android/`, APK
собирается в GitHub Actions (`.github/workflows/android.yml`).

## Запасной Telegram-бот (выключен)

`bot/check.py` + `.github/workflows/outages.yml` — бот, который пишет об
изменениях графика в Telegram из GitHub Actions. Он берёт график из
**неофициальной копии** данных ДТЭК (с серверов GitHub сайт ДТЭК недоступен) и
срабатывает с задержкой 5–15 минут, поэтому по умолчанию выключен. Включить:
переменная `BOT_ENABLED=1`, секрет `TELEGRAM_BOT_TOKEN` (от @BotFather),
переменная `GROUP`.
