# Анализ @AutoHelpKrr и концепция похожего приложения

Дата анализа: 8 ноября 2026. Источник: публичные сообщения группы `t.me/AutoHelpKrr` (через веб-превью Telegram).
Собрано 3000 доступных сообщений из ~4860 (остальные удалены), период с 10.05.2025 по 08.11.2026.

## 1. Что это такое

- **Формат:** это не канал, а **публичная группа (супергруппа)**: 2376 участников, ~680 онлайн.
- **Суть:** волонтёрская взаимопомощь водителей Кривого Рога на дороге, бесплатно.
  Из описания: «прикурить, вытянуть, подвезти топливо, подкачать колесо».
- **Принцип:** «Тут не чатят — тут помогают». Пишут, только когда помощь нужна «здесь и сейчас».
- **Языки:** украинский и русский вперемешку, примерно поровну.

### Экосистема проекта

| Ресурс | Роль |
|---|---|
| `@AutoHelpKrr` (группа) | Основная лента: заявки SOS и ответы «еду» |
| `@AutoHelpKr_chat` | Флуд-чат: общение, поиск шиномонтажа, вопросы не «здесь и сейчас» (с 12.2025) |
| `@autohelp_kr` (канал) | Попытка (12.2025) публиковать заявки в канал с комментариями, без флуда |
| `@autoforum_kr` | Партнёр, городской автофорум (~13 000 подписчиков): технические советы, диагностика |
| `@zapravka_kr` | Партнёр: работающие заправки (актуально во время тревог/отключений) |
| `@Sos_autohelp_bot` | Бот для подачи заявок, запущен 24.09.2026 и **откатан через 6 дней** (см. п. 5) |

| Тип | Упоминаний | Примеры |
|---|---|---|
| Колесо: прокол, замена, запаска, домкрат, балонник, компрессор | ~280 | «Пробила колесо. Нужен балонник», «нужен компрессор, подкачать» |

## 3. Как проходит типичная заявка

```
07:01  Автор:     «Кто может помочь прикурить авто (с собой ничего нет), стою возле Варуса, Восточный‑2»
07:02  Помощник1: «Еду»
07:02  Помощник2: «Сейчас подойду»
07:03  Помощник3: «Так мне ехать или нет?»            ← нет статуса заявки
07:0x  Уточнения: «Яке авто?», «Гео скиньте», «5‑7 хв», номер телефона
07:11  Автор:     «Ещё раз спасибо за помощь ☺️»       ← закрытие вручную
       Помощник:  фото + «+ в карму»                  ← отчёт для доверия
```

Что видно:
- **Реакция быстрая:** первый «еду» часто приходит за 1–5 минут.
- **Обязательные поля** (их всё время переспрашивают): что случилось, точное место (район, улица, ориентир или геопозиция), марка/цвет авто, что есть с собой (трос, провода, запаска), контакт.
- **Коллизии:** выезжают несколько человек сразу, никто не знает, занята ли заявка («Ехать?», «Актуально?»).
- **Закрытие:** вручную: «неактуально», «уже помогли», «отбой». Админ постоянно просит писать, если помощь уже едет.
- **Отчёт:** фото «+ в карму». Админы просят фото/видео, «чтобы видели, что группа работает».
- **Деньги:** помощь бесплатная, но люди часто сами предлагают «компенсирую», «заплачу».
- **География:** город длинный (десятки км), места называют по кварталам, рынкам, заправкам и ТЦ: «95 квартал», «РЛС», «ЮБК», «Соцгород», «Заречный».
- **Время (Киев = UTC+2/+3):** пик с 07:00 до 22:00, утренний всплеск 07–10 (машина не заводится после ночи). Ночью почти пусто.
- **Сезонность:** больше всего сообщений в сентябре 2026 (~490 из доступных); зимой много «прикурить».

## 4. Главные боли (из сообщений админов)

1. **Флуд убивает уведомления.** «Люди отключают звук или выходят, и когда кому-то реально нужна помощь, сообщение не видят». Правило «тишины в эфире» админ напоминает раз в 1–2 недели.
2. **Не по теме:** технические вопросы, поиск шиномонтажа, советы. Их приходится вручную отправлять на автофорум или во флуд-чат.
3. **Нет статуса заявки:** непонятно, едет ли кто-то и решена ли проблема.
4. **Токсичность:** «сам виноват», «не мог накопить на АКБ». Админ публиковал отдельный пост «не осуждать».
5. **Рост:** админы всё время просят звать друзей: «чем больше людей в каждом районе, тем ближе помощь». Был сбор денег на рекламу.
6. **Мотивация помощников:** обещали «вознаграждать активных», есть неформальная «карма».

## 5. Ключевой урок: эксперимент с ботом (24–30.09.2026)

Админы запустили `@Sos_autohelp_bot`:
- пошаговая заявка за 30 секунд (тип → авто → где/геопозиция → контакт);
- автопубликация карточки в группу;
- кнопка «Їду допомагати» и список «Їдуть: …»;
- ссылка на Google Maps;
- статус «✅ Заявку закрито»;
- «📸 Звіт про надану допомогу»;
- топ помощников.

Пример карточки:
```
✅ Заявку закрито | 129 квартал возле садика
Тип: 🔋 Прикурити акумулятор
Авто: Ниссан (электро)
Де: 129 квартал возле садика
Контакт: @…   Автор: @…
Їдуть: @…, @…
💬 Обговорити заявку у чаті: t.me/AutoHelpKr_chat
ℹ️ Потрібна допомога? → @Sos_autohelp_bot
```

**Через 6 дней формат откатили «по многочисленным жалобам».** Что говорили участники:
- «Выглядело не как помощь по доброте душевной, а как заказ бесплатной службы».
- «Создаётся впечатление, что помогать нужно боту, а не живому человеку».
- «Этот спам/срач и делает помощь живой».
- Было и за: «меньше спама, чаще включено уведомление», «из‑за срача реально можно пропустить заявку».
- «Подача интересная, но 3–5 дней на адаптацию мало».

**Вывод для нашего продукта:** структура нужна (статусы, геопозиция, «кто едет»), но:
- **нельзя запрещать писать обычным текстом:** бот должен подхватывать свободные сообщения, а не заменять их;
- карточка должна выглядеть **по-человечески** (имя, «Олег едет, будет через 7 минут»), а не как тикет;
- **живое общение** с автором должно остаться (ответы в треде или комментарии);
- переход нужно делать **постепенно**, с длинным периодом, когда работают оба режима.

## 6. Концепция нашего приложения

### Позиционирование
«Сеть соседской взаимопомощи на дороге» для любого города. Главный KPI: **время до первого «еду»** и **доля закрытых заявок**.

### Платформа: начать с Telegram
Аудитория уже там, ничего не надо устанавливать, есть push, геопозиция и Mini Apps.
1. **Бот + группа города** (MVP).
2. **Telegram Mini App:** карта активных заявок и помощников рядом.
3. Позже, при росте: отдельное мобильное приложение (фоновые гео-уведомления в радиусе).

### MVP: функции
**Для того, кто просит помощи**
- Заявку можно подать **любым способом**: написать текстом в группу (бот сам распознает тип, место и авто и предложит оформить карточку) или через кнопку «🆘 Нужна помощь» в боте за 3 шага: тип (кнопки) → геопозиция/адрес → что есть с собой и как связаться.
- Типы: 🔋 прикурить · 🪢 буксир/вытянуть · 🛞 колесо/запаска/компрессор · ⛽ топливо · 🔑 закрыл ключи · ❓ другое.
- Кнопки «Мне уже помогли» / «Неактуально», плюс автонапоминание через 30–60 минут: «Ещё нужна помощь?».

**Для помощника**
- Профиль: район(ы), что есть с собой (провода, бустер, трос, компрессор, домкрат, канистра, 4x4/фаркоп), время, когда готов помогать.
- Push только по **подходящим** заявкам: рядом (радиус) и по моему снаряжению. Это решает проблему флуда.
- Кнопка «🚗 Еду» с ETA. Остальные видят «Иван уже едет, ~7 мин». Можно «подстраховать», если нужен второй.
- Прямая связь с автором в один клик (контакт раскрывается только тому, кто нажал «еду»).

**Сообщество и доверие**
- Фото-отчёт «+ в карму» → репутация, бейджи, ежемесячный топ помощников.
- Ответ «не по теме» бот уводит автоматически: техвопросы → форум, шиномонтаж/СТО → справочник.
- Справочник: эвакуаторы, выездной шиномонтаж, круглосуточные СТО, работающие во время тревоги/отключения заправки. Пользователи сами его пополняют.
- Отдельный пункт «Не осуждаем»: закреплённые правила плюс мягкая модерация (бот скрывает реплики, если у них поставили много 👎).

**Для админа**
- Статистика: заявок в день, медианное время до первого «еду», % закрытых, карта «белых пятен» (районы без помощников).
- Плановые напоминания правил и автоматизация праздничных постов.
- Мультигород: одна платформа, отдельная группа и админ на каждый город.

### Возможная монетизация (без потери «доброты»)
Помощь всегда бесплатна. Доход:
- партнёрские справочники (эвакуаторы, СТО, шиномонтажи с пометкой «партнёр»);
- донаты на продвижение;
- опциональные «чаевые» помощнику (по желанию автора; в группе многие сами предлагают заплатить).

### Технический стек (предложение)
- **Бот:** Python + aiogram 3 (или TypeScript + grammY), webhook.
- **БД:** PostgreSQL + PostGIS (поиск помощников в радиусе), Redis (очереди, таймеры напоминаний).
- **Распознавание свободного текста:** LLM-классификатор (тип, место, авто, есть ли трос/провода) с подтверждением кнопками.
- **Mini App:** React + Telegram WebApp SDK + карта (Leaflet/MapLibre + OSM).
- **Хостинг:** любой VPS/контейнер, админка на том же бэкенде.

### Модель данных (минимум)
```
User(id, tg_id, name, phone?, city_id, rating, created_at)
HelperProfile(user_id, districts[], equipment[], available_from/to, radius_km, notify)
Request(id, author_id, city_id, type, car, description, location(geo), address_text,
        has_equipment[], status[open|in_progress|resolved|cancelled|expired],
        created_at, first_response_at, resolved_at, group_message_id)
Response(id, request_id, helper_id, eta_min, status[going|arrived|done|cancelled], created_at)
Report(id, request_id, helper_id, photo_file_id, thanks_text)
Directory(id, city_id, category, name, phone, hours, works_during_blackout, verified)
```

## 7. План работ
1. **Неделя 1–2:** бот MVP (заявка кнопками и текстом, карточка в группе, «Еду», закрытие, напоминания) + профиль помощника.
2. **Неделя 3:** гео-уведомления по радиусу/снаряжению, репутация и топ.
3. **Неделя 4:** Mini App с картой, справочник, админ-статистика.
4. Пилот в одном городе: **оставить обычные сообщения рабочими**, бот только «подхватывает» их, A/B по времени отклика.
