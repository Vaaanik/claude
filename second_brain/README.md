# 🧠 Второй мозг в Telegram

Telegram-бот, который запускает Claude Code **на вашем компьютере**. Вы пишете или говорите голосом в Telegram, Claude работает с вашими файлами, программами и терминалом и отвечает в ту же ветку.

- **Голос**: голосовые расшифровываются локально (faster-whisper, бесплатно, ключи не нужны).
- **Ветки по проектам**: каждая тема форум-группы — отдельный проект со своей папкой и своей памятью разговора.
- **Доступ к компу**: Claude читает файлы, пишет код, запускает команды. Перед изменениями и командами бот спрашивает кнопками «Разрешить / Отклонить».
- **Файлы и фото**: присланное в тему сохраняется в `telegram_inbox/` папки проекта, Claude его видит.
- **Только вы**: бот отвечает только Telegram ID из `ALLOWED_USER_IDS`.

## Установка (один раз)

### 1. Claude Code
Установите Claude Code и войдите в аккаунт: https://code.claude.com/docs
```bash
claude   # при первом запуске попросит войти
```
Либо вместо входа укажите `ANTHROPIC_API_KEY` в `.env`.

### 2. Бот в Telegram
1. Откройте **@BotFather** → `/newbot` → имя «Второй мозг» → скопируйте токен.
2. Там же: `/mybots` → ваш бот → **Bot Settings → Group Privacy → Turn off** (чтобы бот видел сообщения в группе).

### 3. Группа с ветками
1. Создайте группу в Telegram, добавьте туда бота.
2. Настройки группы → **Темы (Topics) → включить**.
3. Сделайте бота **администратором** группы.
4. Создайте темы под проекты: «Работа», «Сайт», «Идеи», «Финансы»…

### 4. Запуск
Нужен Python 3.10+.
```bash
git clone https://github.com/vaaanik/claude.git
cd claude/second_brain
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
```
Откройте `.env`, вставьте токен бота. Свой ID узнайте у **@userinfobot** и впишите в `ALLOWED_USER_IDS`.
```bash
python bot.py
```
При первом голосовом скачается модель распознавания (~500 МБ для `small`), это один раз.

## Как пользоваться

**Темы сам создаёт бот.** Создайте группу, включите в ней Темы и сделайте бота администратором с правом управлять темами. Затем напишите в общей теме: «создай темы для проектов: Ремонт, Учёба, Работа». У каждой темы будет своя папка в `~/projects/` и своя память разговора.

**Память на сервере.**
- `~/second-brain/memory/about.md` — общая память о вас, видна из всех тем. Скажите «запомни, что…», и бот запишет.
- `CLAUDE.md` в папке темы — заметки проекта: цели, решения, статус.

Эти файлы переживают перезапуски, команду `/new` и обновления бота.

Темы можно привязывать к папкам и вручную:

В каждой теме один раз привяжите папку проекта:
```
/project ~/projects/my-site
```
Дальше просто пишите или говорите голосом в тему — Claude помнит весь разговор в ней.

| Команда | Что делает |
|---|---|
| `/project <путь>` | привязать тему к папке (создаст её, если нет) |
| `/new` | начать разговор в теме заново |
| `/stop` | прервать текущую задачу |
| `/where` | показать папку и сессию темы |
| `/id` | ваш Telegram ID |

Идея для «второго мозга»: тема **«Заметки»** с `/project ~/second-brain/notes` — надиктовываете мысли, а Claude раскладывает их по файлам и потом находит по запросу.

## Подключение Google (почта, календарь, Диск)

Один раз нужно создать «ключ» в Google Cloud — это бесплатно.

1. Откройте https://console.cloud.google.com → создайте проект (например, «Second Brain»).
2. **APIs & Services → Library**: включите **Gmail API**, **Google Calendar API**, **Google Drive API**.
3. **APIs & Services → OAuth consent screen** (или **Google Auth Platform**): тип **External**, название любое, свой email. В **Audience** добавьте свой Gmail в **Test users**, затем нажмите **Publish app** (иначе доступ слетает каждые 7 дней).
4. **Credentials → Create credentials → OAuth client ID** → тип **Desktop app**. Скопируйте **Client ID** и **Client secret**.
5. Впишите их в `.env` (`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`) и перезапустите бота.
6. Отправьте боту `/google` и следуйте инструкции. Google предупредит, что приложение не проверено, — это ваше собственное приложение: «Дополнительно» → «Перейти».

Бот читает почту, календарь и Диск сам. Отправка писем и создание/удаление событий — только после вашей кнопки «Разрешить».

## Вариант без своего компьютера: облачный сервер 24/7

Если ноутбук обычно выключен, запустите бота на арендованном сервере (VPS). Тогда «компьютер», к которому у Claude есть доступ, — это сервер: там живут папки проектов и заметки, там Claude запускает код и команды. Файлы с ноутбука ему не видны, их нужно прислать в Telegram или держать в GitHub.

1. Арендуйте сервер с **Ubuntu 24.04**, минимум **2 ГБ RAM** (лучше 4 ГБ). Подойдёт любой хостинг: Hetzner, DigitalOcean, Timeweb, Aeza и др. — обычно 4–8 $ в месяц.
2. Получите API-ключ на https://console.anthropic.com (оплата за использование, отдельно от подписки Claude).
3. Зайдите на сервер (`ssh root@IP` или веб-консоль хостинга) и выполните:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/vaaanik/claude/second-brain-bot/second_brain/deploy/setup.sh | bash
   ```
4. Заполните `.env` и запустите:
   ```bash
   nano /home/brain/claude/second_brain/.env   # токен бота, ваш ID, ANTHROPIC_API_KEY
   systemctl restart second-brain
   ```
Бот сам перезапускается при сбоях и после перезагрузки сервера. Логи: `journalctl -u second-brain -f`.

На сервере с 2 ГБ памяти поставьте в `.env` `WHISPER_MODEL=base` — распознавание чуть хуже, зато легче.

## Чтобы бот работал постоянно на своём компьютере

Бот работает, пока запущен `python bot.py` и компьютер включён.

- **macOS / Linux**: запустите в `tmux`/`screen`, или настройте автозапуск (launchd / systemd).
- **Windows**: «Планировщик заданий» → задача «При входе в систему» → запуск `.venv\Scripts\python.exe bot.py` в папке `second_brain`.

## Безопасность

- Бот = доступ к вашему компьютеру. **Никому не давайте токен** и не добавляйте в группу посторонних.
- `PERMISSIONS=ask` (по умолчанию) — каждое изменение файлов и каждая команда требуют вашего нажатия. `auto` — без вопросов; включайте, только если понимаете риск.
- Чтение файлов и поиск в интернете разрешены без вопросов.
