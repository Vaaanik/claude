# 🧠 Второй мозг в Telegram

Telegram-бот, который запускает Claude Code **на вашем компьютере**. Вы пишете или говорите голосом в Telegram, Claude работает с вашими файлами, программами и терминалом и отвечает в ту же ветку.

- **Голос**: голосовые расшифровываются локально (faster-whisper, бесплатно, ключи не нужны).
- **Ветки по проектам**: каждая тема форум-группы — отдельный проект со своей папкой и своей памятью разговора.
- **Доступ к компу**: Claude читает файлы, пишет код, запускает команды. Перед изменениями и командами бот спрашивает кнопками «Разрешить / Отклонить».
- **Файлы и фото**: присланное в тему сохраняется в `telegram_inbox/` папки проекта, Claude его видит.
- **Только вы**: бот отвечает только Telegram ID из `ALLOWED_USER_IDS`.

## Установка (один раз)

### 1. Claude Code
Установите Claude Code и войдите в аккаунт: https://code.claude.com/docs
```bash
claude   # при первом запуске попросит войти
```
Либо вместо входа укажите `ANTHROPIC_API_KEY` в `.env`.

### 2. Бот в Telegram
1. Откройте **@BotFather** → `/newbot` → имя «Второй мозг» → скопируйте токен.
2. Там же: `/mybots` → ваш бот → **Bot Settings → Group Privacy → Turn off** (чтобы бот видел сообщения в группе).

### 3. Группа с ветками
1. Создайте группу в Telegram, добавьте туда бота.
2. Настройки группы → **Темы (Topics) → включить**.
3. Сделайте бота **администратором** группы.
4. Создайте темы под проекты: «Работа», «Сайт», «Идеи», «Финансы»…

### 4. Запуск
Нужен Python 3.10+.
```bash
git clone https://github.com/vaaanik/claude.git
cd claude/second_brain
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
```
Откройте `.env`, вставьте токен бота. Свой ID узнайте у **@userinfobot** и впишите в `ALLOWED_USER_IDS`.
```bash
python bot.py
```
При первом голосовом скачается модель распознавания (~500 МБ для `small`), это один раз.

## Как пользоваться

В каждой теме один раз привяжите папку проекта:
```
/project ~/projects/my-site
```
Дальше просто пишите или говорите голосом в тему — Claude помнит весь разговор в ней.

| Команда | Что делает |
|---|---|
| `/project <путь>` | привязать тему к папке (создаст её, если нет) |
| `/new` | начать разговор в теме заново |
| `/stop` | прервать текущую задачу |
| `/where` | показать папку и сессию темы |
| `/id` | ваш Telegram ID |

Идея для «второго мозга»: тема **«Заметки»** с `/project ~/second-brain/notes` — надиктовываете мысли, а Claude раскладывает их по файлам и потом находит по запросу.

## Чтобы бот работал постоянно

Бот работает, пока запущен `python bot.py` и компьютер включён.

- **macOS / Linux**: запустите в `tmux`/`screen`, или настройте автозапуск (launchd / systemd).
- **Windows**: «Планировщик заданий» → задача «При входе в систему» → запуск `.venv\Scripts\python.exe bot.py` в папке `second_brain`.

## Безопасность

- Бот = доступ к вашему компьютеру. **Никому не давайте токен** и не добавляйте в группу посторонних.
- `PERMISSIONS=ask` (по умолчанию) — каждое изменение файлов и каждая команда требуют вашего нажатия. `auto` — без вопросов; включайте, только если понимаете риск.
- Чтение файлов и поиск в интернете разрешены без вопросов.
